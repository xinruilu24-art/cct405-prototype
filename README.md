# CCT405 游戏原型：案件代理人

可玩的 HTML 原型。在线试玩：https://xinruilu24-art.github.io/cct405-prototype/

本地试玩：下载 index.html，用浏览器打开。

新手指引：开场点击逐条阅读阿紫消息，再从手机主界面开始浮窗导览，依次认识各 App 和左侧数值。导览不消耗资源，可以跳过，并可从阿紫聊天或设置中重看。

限定截图取证：仅指定内容显示「截图取证」，保存后可在证据清单、相册和反驳中使用。当前可截图名单留空，配置方式见 [SCREENSHOT_EVIDENCE.md](SCREENSHOT_EVIDENCE.md)。
