# CCT405 游戏原型：案件代理人

可玩的 HTML 原型。在线试玩：https://xinruilu24-art.github.io/cct405-prototype/

本地试玩：下载 index.html，用浏览器打开。

新手指引：点手机屏幕逐条阅读阿紫消息，再从手机主界面开始浮窗导览。浮窗紧邻当前操作或指标，玩家逐个点击高亮的真实操作位置；练习不会实施行动，也不会改变时间、余额、舆论、压力或证据。效果以文字描述，包含收藏证据和公告。导览结束后回到阿紫聊天，由她作结，再交给玩家自行探索。可以跳过，也可从阿紫聊天或设置中重看。

收藏证据：可收藏材料和正式发布的对赌公告，点击帖子底部星星进入证据清单，不消耗行动点。截图功能已删除。配置说明见 [EVIDENCE_COLLECTION.md](EVIDENCE_COLLECTION.md)，公告改编说明见 [LIVESTREAM_RULES_SOURCE.md](LIVESTREAM_RULES_SOURCE.md)。

画师聊天：点手机屏幕逐条展开回复和文件，读完后再推进时段及播放转场。评论回复等非聊天行动短暂展示结果后自动转场，无需再点一次。

过程视频：在画师的 MiChat 聊天中提出制作请求，读完她对耗时的说明后选择同意或暂时不做。同意后制作发布，展示完回复后消耗两个时段；拒绝不会发布，也不消耗时段。

直播对赌：从画师聊天提出，先阅读压力说明再确认；确认使画师 1 压力 +20、画师 2 +30。她回复将直播约在第五天，读完后发布规则公告，再消耗一个行动点。拒绝不增加压力或扣点。画师 1 至少保有 ¥50，画师 2 至少保有 ¥80。发起和开播前均检查资格；当前规则检查余额，不另扣保证金。

普通支持评论回复使舆论 +2；转发帖子及点外卖各消耗一个行动点。转发先读完画师回复再推进时段。

验证：`node --test tests/*.test.cjs`。

咪画师消息：客户聊天底部可以回复。客户布丁第二天出现，索取后会逐条发来说明和两次约稿过程记录；读到材料时自动加入证据清单，可用于回应和直播。小葵可提供已有订单时间线，阿青可提供订单核对记录。阅读和这类取证回复不消耗行动点，重复打开不会重复领取。教程使用独立预览，不会提前解锁客户或发送消息。

第三天事件：第三天早上，指控方发布新的鉴定帖（n5），舆论 -20、画师压力 +10，仅触发一次。自动打开画师聊天显示提醒，点手机展开新帖子卡片，点卡片进入正文；帖子同时置于小粉书信息流首位，可以按原有规则回应评论或转发。阅读提醒、打开帖子不会额外扣行动点或重复结算事件。
