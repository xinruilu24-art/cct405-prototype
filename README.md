# CCT405 游戏原型：案件代理人

可玩的 HTML 原型。在线试玩：https://xinruilu24-art.github.io/cct405-prototype/

本地试玩：下载 index.html，用浏览器打开。

新手指引：点手机屏幕逐条阅读阿紫消息，再从手机主界面开始浮窗导览。浮窗紧邻当前页面或指标，效果以文字描述。导览结束后回到阿紫聊天，由她作结，再交给玩家自行探索。可以跳过，也可从阿紫聊天或设置中重看。

限定截图取证：仅指定内容显示「截图取证」，保存后可在证据清单和反驳中使用。目前开放《直播对赌规则公告》，可从小粉书或发布页的规则入口打开；其他名单保持未开放。配置方式见 [SCREENSHOT_EVIDENCE.md](SCREENSHOT_EVIDENCE.md)，公告改编说明见 [LIVESTREAM_RULES_SOURCE.md](LIVESTREAM_RULES_SOURCE.md)。

画师聊天：点手机屏幕逐条展开回复和文件，读完后再推进时段及播放转场。评论回复等非聊天行动短暂展示结果后自动转场，无需再点一次。

过程视频：在画师的 MiChat 聊天中提出制作请求，读完她对耗时的说明后选择同意或暂时不做。同意后制作发布，展示完回复后消耗两个时段；拒绝不会发布，也不消耗时段。

直播对赌：画师 1 至少保有 ¥50，画师 2 至少保有 ¥80。发起和开播前均检查资格；当前规则检查余额，不另扣保证金。
